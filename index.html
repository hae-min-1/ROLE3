구글 스프레드시트 연동
* 구글 시트 주소(https://docs.google.com/spreadsheets/d/...)를 그대로 넣으셔도 바로 불러올 수 있습니다!
💡 구글 스프레드시트 주소로 바로 불러오기 안내:
구글 시트 우측 상단의 [공유] 버튼을 누르고, [일반 액세스]를 '링크가 있는 모든 사용자 (역할: 뷰어)'로 설정한 후 링크를 복사해 붙여넣으시면 Apps Script 배포 없이도 학생 명단과 역할을 즉시 불러올 수 있습니다.
⚡ 가장 빠르고 확실한 방법:
구글 스프레드시트나 엑셀에서 학생 명단과 역할 범위를 드래그하여 Ctrl+C (복사)한 뒤, 아래 칸에 Ctrl+V (붙여넣기) 하시면 권한 설정 없이 즉시 1초 만에 불러옵니다!
* 첫 행의 제목(번호, 이름, 역할 등)은 자동으로 감지하여 제외됩니다.
⚠️ "모든 사용자"로 설정했는데도 권한 확인 안내가 나오는 이유:
  1. 스프레드시트 링크 vs Apps Script URL 구분:
    스프레드시트 주소를 넣으셨다면 시트 우측 상단 [공유] → [일반 액세스]가 '링크가 있는 모든 사용자'로 되어 있어야 합니다.
  2. Apps Script [새 배포] 시 가장 흔한 실수:
    - [다음 사용자 권한으로 앱 실행]: 반드시 "나 (내 계정, Me)"로 지정해야 합니다.
    (⚠️ '웹 앱에 액세스하는 사용자'로 지정하면 브라우저 요청 시 구글 로그인 인증이 요구되어 차단됩니다!)
    - [액세스 권한이 있는 사용자]: "모든 사용자 (Anyone)"
  3. 주소 끝부분: 반드시 `/exec`로 끝나야 합니다. (`/dev`는 개발자 전용이라 외부 호출이 차단됩니다) 
// 1인 1역할 구글 시트 연동 스크립트 (JSONP & CORS 완벽 지원)
function doGet(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getActiveSheet();
  var data = sheet.getDataRange().getValues();
  
  var students = [];
  var roles = [];
  
  // 첫 번째 행은 제목(헤더)으로 간주하고 1행부터 읽음
  for (var i = 1; i < data.length; i++) {
    var row = data[i];
    if (row[0] !== "" && row[0] !== null) {
      students.push(String(row[0]).trim());
    }
    if (row[1] !== "" && row[1] !== null) {
      roles.push({
        icon: "⭐",
        title: String(row[1]).trim(),
        desc: row[2] ? String(row[2]).trim() : "우리 반을 위한 소중한 역할이에요."
      });
    }
  }
  
  var result = {
    status: "ok",
    students: students,
    roles: roles
  };
  
  // JSONP 콜백 파라미터 지원 (브라우저 CORS 제약 100% 우회)
  var callback = e && e.parameter && e.parameter.callback;
  if (callback) {
    return ContentService.createTextOutput(callback + '(' + JSON.stringify(result) + ')')
      .setMimeType(ContentService.MimeType.JAVASCRIPT);
  }
  
  return ContentService.createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var params = JSON.parse(e.postData.contents);
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("배정결과") || ss.insertSheet("배정결과");
  sheet.clear();
  sheet.appendRow(["번호", "학생 이름", "담당 역할", "역할 설명"]);
  if (params.assignments && params.assignments.length) {
    params.assignments.forEach(function(row) {
      sheet.appendRow([row.index, row.student, row.role, row.desc]);
    });
  }
  return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
    .setMimeType(ContentService.MimeType.JSON);
}
